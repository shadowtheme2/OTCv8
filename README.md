# OTCv8

Este repositório contém scripts diversos. Foi adicionado `chess_game.py`, um jogo
simples de xadrez em linha de comando.

## `chess_game.py`

Execute com Python 3. Pode escolher relógio de 5 ou 10 minutos para cada
jogador passando `5` ou `10` como primeiro argumento. Opcionalmente passe
`flip` como segundo argumento para iniciar com o tabuleiro invertido.

Exemplo:

```bash
python3 chess_game.py 5 flip
```

Durante o jogo, digite movimentos no formato `e2e4` ou `flip` para alternar a
visão do tabuleiro.
